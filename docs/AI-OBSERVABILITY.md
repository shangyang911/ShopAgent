# AI 运行面板与 SKU 工具

入口：侧栏“AI 运行” → `/ai-observability`。沿用管理员登录态，当前只允许查看、反馈和导出自己的请求轨迹；不会跨账号暴露会话。旧会话没有历史运行指标，不会凭空回填。

## 记录方式

服务端真实 WebSocket 请求开始处理后，记录独立 `agent_traces` 表。文字、语音、确认、撤销和直接建工单均可形成轨迹。每次实际执行尝试独立ID，同一请求编号的结果重放会标记 `replayed`，没有再次调用模型时记零模型Token。

轨迹记录：模型配置名、Prompt哈希、工具定义哈希、请求类型、经过基础脱敏的限长问题/答案摘要、模型调用用量和耗时、工具名、允许记录的查询参数、结果字段/条数摘要、失败码、拒答/引用降级状态。不会复制原始系统提示词、HTTP请求头、Cookie、供应商异常正文或整个订单结果。基础脱敏支持长数字、邮箱及常见Key/Token格式，不等于全面敏感信息识别；本地调试记录仍需限制访问及保留期限。

记录在独立短事务中进行；写入异常只记录错误类型，不回滚业务操作。回答保存后立即写检查点，用户可在播报期间反馈；后续完成状态更新不覆盖反馈。请求状态沿用协议 `running/completed/failed/cancelled`，取消播报可能已收到文字；完成率仅表示请求处理状态，不代表任务或答案正确。

## 指标口径

- 范围为近1/7/30/90天、当前账号最多最近2000条轨迹，显示期间总数和实际样本数；列表独立分页及状态/反馈筛选。
- 回答P50/P95从服务端process开始至回答持久化测量。语音包含录音/识别等待，播报不计入回答耗时；总耗时包含后续播报等。
- 工具成功率按工具执行是否返回业务错误计算，缺少知识片段但检索调用成功不视为工具异常；它不是工具选择准确率。
- Token来自供应商实际返回，缺失时为未知。模型失败而没有返回用量时保持未知。没有模型调用的确认/重放请求记零。
- 费用以当前模型配置的每百万输入/输出Token单价估算，单位CNY：`AGENT_INPUT_PRICE_PER_MILLION`、`AGENT_OUTPUT_PRICE_PER_MILLION`。未配置、不合法或用量不全时未知。汇总明确显示已知部分与覆盖条数，不等于供应商账单；ASR/TTS、缓存和分级定价费用不包含在内。更改模型时需同时更新价格，历史估算快照不重算。

## 反馈与复评

新回答下方可点“有帮助/需改进”，运行面板可补充500字以内说明。每个轨迹保留一份当前反馈，重复提交只更新，不累加票数。JSON导出保留脱敏问题、观察结果、工具轨迹和版本哈希，标记 `requires_review`；观察答案不自动成为标准答案。

复评流程：筛选失败/负反馈 → 查看原因与调用链 → 导出样例 → 人工核对预期工具及合成业务数据 → 加入 `evals/cases.py` → 运行离线/真实模型评测并对比基线。面板不会自动重放真实订单写操作。

## SKU 商品查询

`search_products` 改为每行一个SKU，支持商品名称/编码、商品ID、SKU编码、颜色、尺寸、是否仅查启用规格和最多20条。颜色/尺寸/编码按不区分大小写的精确值筛选。默认排除停用SKU与不可售商品；零库存SKU仍返回，并明确缺货，不臆造可售数量。

每行返回该规格价格、可售、预留、在库、商品状态及可售标志；可售已扣预留，不再次相减。返回匹配总数、截断标记及匹配SKU价格范围（并非某个指定规格价格）。无匹配明确为空；旧商品无SKU时不根据聚合库存伪造规格，也不在查询时迁移数据。

验证：`tests/test_observability.py` 覆盖真实WebSocket记录、失败码、重放、用量/成本、反馈、账号隔离及多SKU价格库存筛选；Agent任务集v3增加规格查询与无匹配两类任务，现为16场景80条表述。真实模型工具选择准确率仍需单独live评测。
