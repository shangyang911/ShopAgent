# 门店知识库与 RAG 证据链

入口：运营助手 → 门店知识库（`/knowledge`）。系统初始不写入任何真实门店政策；仅测试夹具包含合成政策。

## 版本生命周期

支持粘贴纯文本/Markdown，也可在浏览器读取 `.txt`/`.md` 文件。文档标识用于关联同一政策，版本号不可重复。正文最多50000字符，以标题分段，600字符窗口、80字符重叠；每个片段保留章节和稳定的“版本ID:段号”。

版本先保存为草稿，经管理员核对后发布；已发布内容不可编辑，需创建新版本。版本包含生效日、可选失效日（含当日）、创建账号、发布时间、撤回时间、SHA-256内容指纹。版本和引用只增不覆盖。

当前适用版本按中国标准时间日期判断：同一文档标识取已经开始生效、最后发布的新版本。未来版本不会提前覆盖旧版；最新适用版过期或撤回后，**不会自动恢复旧版**。仅草稿和未来版本不会参与当前政策回答。系统新增 `knowledge_versions` 表，启动流程按已有方式创建，不变更原业务表。

## 检索方法与范围

本地检索不依赖外部服务：中文双字词/英文词BM25，字符三元组TF-IDF余弦向量相似度，RRF融合后按查询覆盖度重排。通用词（如“期限”“规则”）单独重叠不能视为相关，避免已过期保修政策误命中退货期限。

这是可复现的字面混合检索，**不是神经语义Embedding检索**。同义词、跨语言和隐含意图召回仍有限；后续应基于真实门店问答集评估后，再接入语义Embedding或模型重排。词项和向量在生效文档快照上内存构建，面向当前小型门店语料，不宣称大规模向量数据库能力。

## Agent 使用

默认 `AGENT_KNOWLEDGE_SOURCE=local`，真实 Agent 通过自己的数据库会话调用相同检索服务。选择 `cloud` 时使用原百炼知识库；云端片段必须有 `version`、`effective_from`、可选 `effective_until`、`is_current: true` 元数据，否则不会作为当前政策依据。云端当前版本标识需由云端知识库维护，不能从Top-K结果推断。

模型必须返回本轮检索片段的 `citations` ID数组。服务端只接受实际检索ID；缺失或伪造引用时，丢弃解释并降级显示检索原文。无相关有效文档直接拒答；政策问答未实际检索也拒绝确认政策。片段内指令不能授权创建取消动作或人工工单。

回答保存引用快照：标题、版本、有效期、章节、原文片段、内容指纹和检索时间。前端展开查看证据，并可跳转版本原文与当前状态。历史对话引用展示当时快照，不随政策变更覆盖；旧消息缺少元数据时明确标注未提供。

引用合法性校验仅证明来源存在，**不能证明每句模型解释都被原文蕴含**。还需要人工抽检、真实模型回答忠实度评测和业务验收，不能将这套机制宣传成零幻觉。

## 验证与评测

```powershell
cd backend
.venv\Scripts\python.exe -m unittest discover -s tests -p test_knowledge.py -v
.venv\Scripts\python.exe -m evals.rag
.venv\Scripts\python.exe -m evals.runner --mode offline
```

RAG独立评测用隔离内存数据库，固定时间2026-11-02，7份合成版本、20个问题。指标为Recall@5、MRR、无依据问题拒答率；测试覆盖旧版、未来、过期、草稿、撤回和泛词误命中。报告保存 `.local-test/rag-evals/`。这不是生产语料或真实模型回答准确率；原Agent任务集仍使用固定检索夹具验证引擎协议。

管理员均沿用项目现有登录权限。知识库查看、搜索、发布、撤回均要求登录；不新增外部账号、生产政策或付费调用。云端API和本地知识查询不会绕过管理员身份校验。
